Терминальный клиент (TUI) для Яндекс Музыки, написанный на Rust с использованием библиотеки Ratatui.

---

## Реализованный функционал

- **Моя волна** — персональный бесконечный поток рекомендаций с фоновой подгрузкой треков.
- **Медиатека** — доступ к вашим лайкнутым трекам, избранным исполнителям (с их дискографией) и плейлистам.
- **Поиск** — поиск по трекам, исполнителям, альбомам и плейлистам с переключением фильтров по `Tab`. Поиск работает даже без авторизации.
- **Качество звука** — переключение на лету клавишей `~`:
  - FLAC / Lossless (требуется активная подписка Яндекс Плюс);
  - MP3 320 kbps;
  - AAC 192 kbps;
  - AAC 64 kbps.
- **Авторизация**:
  - Вход через встроенное окно Webview (OAuth Яндекс);
  - Ручной ввод готового токена (в интерфейсе или аргументом командной строки).
- **Управление воспроизведением** — перемотка, пауза, регулировка громкости с возможностью сохранения в конфиг.

## Управление (горячие клавиши)

### Навигация и экраны
| Клавиша | Действие |
|---|---|
| `1` | Перейти в «Мою волну» |
| `2` | Открыть Медиатеку (Треки / Артисты / Плейлисты) |
| `3` или `/` | Открыть Поиск |
| `Tab` / `Shift+Tab` | Переключение вкладок медиатеки / фильтров поиска |
| `↑` / `↓` | Перемещение курсора по списку вверх / вниз |
| `PgUp` / `PgDn` | Прокрутка списка на 10 элементов |
| `Home` / `End` | В начало / конец списка |
| `Enter` | Воспроизвести трек / открыть артиста или плейлист |
| `Esc` | Назад / выйти из режима ввода текста |
| `r` | Обновить текущий экран / перезагрузить поток волны |
| `q` / `Ctrl+C` | Выход из приложения |

### Воспроизведение
| Клавиша | Действие |
|---|---|
| `Пробел` | Пауза / Возобновление |
| `n` | Следующий трек |
| `p` | Предыдущий трек |
| `←` / `→` | Перемотка назад / вперёд на 5 секунд |
| `+` / `-` (или `]`/`[`, `Ctrl+↑`/`Ctrl+↓`) | Изменение громкости (шаг 5%) |
| `m` | Заглушить / включить звук (Mute) |
| `~` | Переключить качество звука (FLAC → MP3 → AAC) |
| `Ctrl+S` | Сохранить текущий уровень громкости в конфиг |

### Авторизация
| Клавиша | Действие |
|---|---|
| `l` | Открыть окно авторизации Яндекс (Webview) |
| `t` | Ввести токен вручную (на экране входа) |
| `o` | Выйти из аккаунта (Logout) |

## Сборка и установка (Linux)

### 1. Системные зависимости

Для вывода звука через ALSA и работы окна авторизации (WebKitGTK) требуются пакеты разработчика:

**Ubuntu / Debian / Linux Mint:**
```bash
sudo apt update
sudo apt install -y build-essential pkg-config libasound2-dev libwebkit2gtk-4.1-dev libssl-dev
```
*(В старых дистрибутивах пакет может называться `libwebkit2gtk-4.0-dev`).*

**Arch Linux / Manjaro:**
```bash
sudo pacman -S --needed base-devel alsa-lib webkit2gtk-4.1
```

**Fedora / RHEL:**
```bash
sudo dnf install pkgconf-pkg-config alsa-lib-devel webkit2gtk4.1-devel openssl-devel
```

### 2. Сборка из исходников

Требуется установленный Rust (edition 2024 / версия 1.85+):

```bash
git clone https://github.com/quesas/yandex-music-tui.git
cd yandex-music-tui
cargo build --release
```

Скомпилированный бинарник будет находиться по пути:  
`./target/release/yandex-music-tui`

---

## Запуск и флаги командной строки

```bash
# Обычный запуск плеера
./target/release/yandex-music-tui

# Открыть графическое окно авторизации (Webview OAuth)
./target/release/yandex-music-tui --login

# Авторизоваться по готовому токену
./target/release/yandex-music-tui --token "ВАШ_ТОКЕН"

# Сбросить сохранённый токен (выйти из аккаунта)
./target/release/yandex-music-tui --logout

# Справка по флагам
./target/release/yandex-music-tui --help
```

Файл конфигурации сохраняется по стандарту XDG:  
`~/.config/yandex-music-tui/config.toml`
