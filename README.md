# yandex-music-tui

> # ⚠️ ВНИМАНИЕ: ЭТО ПЕРВАЯ ВЕРСИЯ!
> ## ПРОЕКТ В РАННЕЙ РАЗРАБОТКЕ, МНОГОЕ ЕЩЁ ПРЕДСТОИТ СДЕЛАТЬ!
> Возможны баги, падения и шероховатости интерфейса. Пуллреквесты, багрепорты и предложения по улучшению только приветствуются.

Терминальный клиент (TUI) для Яндекс Музыки, написанный на Rust с использованием библиотеки Ratatui.

---

## Реализованный функционал

- **Моя волна** — персональный бесконечный поток рекомендаций с фоновой подгрузкой треков. Будущие треки скрыты и открываются по мере воспроизведения.
- **Настройка Моей волны** — гибкая конфигурация как в оригинальном клиенте (клавиша `w` или `4` → «Настройки Моей волны»): занятие («Засыпаю», «В дороге», «Тренируюсь»…), настроение («Весёлое», «Грустное», «Спокойное», «Бодрое»), язык («Русский», «Иностранный», «Без слов») и характер рекомендаций («Любимое», «Незнакомое», «Популярное»). Выбранные параметры сохраняются в конфиге и применяются к новой сессии волны.
- **Медиатека** — доступ к вашим лайкнутым трекам, избранным исполнителям (с их дискографией) и плейлистам.
- **Поиск** — поиск по трекам, исполнителям, альбомам и плейлистам с переключением фильтров по `Tab`. Поиск работает даже без авторизации.
- **Качество звука** — переключение на лету клавишей `~`:
  - Превосходное — без потерь (требуется активная подписка Яндекс Плюс);
  - Высокое — 320 кбит/с;
  - Среднее — 192 кбит/с;
  - Низкое — 64 кбит/с.
  Выбранное качество сразу применяется к текущему треку и сохраняется в конфиге.
- **Авторизация**:
  - Вход через страницу Яндекс OAuth в системном браузере; после входа кнопка «Открыть приложение» возвращает токен в TUI через зарегистрированный обработчик `music-application://`;
  - Ручной ввод готового токена или адреса кнопки «Открыть приложение» (в интерфейсе или аргументом командной строки).
- **Управление воспроизведением** — перемотка, пауза, регулировка громкости с возможностью сохранения в конфиг.
- **Интеграция с рабочим столом** — плеер публикует интерфейс MPRIS (`org.mpris.MediaPlayer2.yandex-music-tui`): управление из панели задач, медиа-виджетов GNOME/KDE, `playerctl` и мультимедийных клавиш.
- **Перемешивание** — клавиша `s` перемешивает треки текущего списка и очередь воспроизведения, сохраняя текущий трек.
- **Лайки и дизлайки** — отметки «Мне нравится» (`f`) и «Не рекомендовать» (`d`) с мгновенной синхронизацией с аккаунтом Яндекс Музыки:
  - Любимые треки помечаются красным символом `♥`, дизлайкнутые — серым `✗`;
  - В «Моей волне» оценивается играющий трек, а в медиатеке, результатах поиска и треклистах — выбранный курсором (или текущий, если курсор не на треке);
  - При установке лайка трек сразу добавляется в вашу медиатеку (а дизлайк снимается);
  - При дизлайке или снятии лайка трек автоматически исключается из списка любимых треков.
- **Настройки** — экран `4`: выбор темы интерфейса (Белая, Чёрная, TokyoNight, RosePine), качества звука по умолчанию (Превосходное, Высокое, Среднее, Низкое) и переход к настройкам Моей волны.
- **Подсказки** — клавиша `?` открывает меню со всеми горячими клавишами.

## Управление (горячие клавиши)

### Навигация и экраны
| Клавиша | Действие |
|---|---|
| `1` | Перейти в «Мою волну» |
| `2` | Открыть Медиатеку (Треки / Артисты / Плейлисты) |
| `3` или `/` | Открыть Поиск |
| `4` или `,` | Открыть Настройки |
| `w` | Настроить Мою волну |
| `Tab` / `Shift+Tab` | Переключение вкладок медиатеки / фильтров поиска |
| `↑` / `↓` | Перемещение курсора по списку вверх / вниз |
| `PgUp` / `PgDn` | Прокрутка списка на 10 элементов |
| `Home` / `End` | В начало / конец списка |
| `Enter` | Воспроизвести трек / открыть артиста или плейлист |
| `Esc` | Назад / выйти из режима ввода текста |
| `r` | Обновить текущий экран / перезагрузить поток волны |
| `s` | Перемешать треки текущего списка (и очередь воспроизведения) |
| `?` | Открыть меню со всеми подсказками по клавишам |
| `q` | Выход из приложения (с подтверждением) |
| `Ctrl+C` | Выход из приложения без подтверждения |

### Настройки
| Клавиша | Действие |
|---|---|
| `↑` / `↓` | Выбор настройки |
| `Enter`, `←` / `→` | Изменить значение настройки |
| `Esc` | Вернуться на предыдущий экран |

### Настройки Моей волны
| Клавиша | Действие |
|---|---|
| `w` | Открыть настройки волны (также доступно из экрана `4`) |
| `↑` / `↓` | Выбор параметра |
| `←` / `→` или `Enter` | Переключить значение |
| `a` | Применить и перезапустить волну |
| `Esc` | Назад (изменения применяются автоматически) |

### Воспроизведение
| Клавиша | Действие |
|---|---|
| `Пробел` | Пауза / Возобновление |
| `n` | Следующий трек |
| `p` | Предыдущий трек |
| `←` / `→` | Перемотка назад / вперёд на 5 секунд |
| `+` / `-` (или `]`/`[`, `Ctrl+↑`/`Ctrl+↓`) | Изменение громкости (шаг 5%) |
| `Shift+↑` / `Shift+↓` | Изменение громкости (шаг 1%) |
| `m` | Заглушить / включить звук (Mute) |
| `f` | Поставить / снять лайк (в «Моей волне» — текущему треку, в списках — выбранному) |
| `d` | Поставить / снять дизлайк («Не рекомендовать»; в «Моей волне» — текущему треку, в списках — выбранному) |
| `~` | Переключить качество звука (Превосходное → Высокое → Среднее → Низкое) |
| `Ctrl+S` | Сохранить текущий уровень громкости в конфиг |

### Авторизация
| Клавиша | Действие |
|---|---|
| `l` | Открыть страницу авторизации Яндекс в браузере |
| `t` | Ввести токен или URL редиректа вручную (на экране входа) |
| `o` | Выйти из аккаунта (с подтверждением) |

## Сборка и установка (Linux)

### 1. Системные зависимости

Для вывода звука через ALSA требуются пакеты разработчика:

**Ubuntu / Debian / Linux Mint:**
```bash
sudo apt update
sudo apt install -y build-essential pkg-config libasound2-dev
```

**Arch Linux / Manjaro:**
```bash
sudo pacman -S --needed base-devel alsa-lib
```

**Fedora / RHEL:**
```bash
sudo dnf install pkgconf-pkg-config alsa-lib-devel
```

### 2. Сборка из исходников

Требуется установленный Rust (edition 2024 / версия 1.85+):

```bash
git clone https://github.com/quesas/yandex-music-tui.git
cd yandex-music-tui
cargo build --release
```

Скомпилированный бинарник будет находиться по пути:  
`./target/release/yandex-music-tui`

Каталог `target/` — это кэш сборки, он исключён из git и не входит в поставку. Сам бинарник весит около 10–15 МБ; при желании кэш можно удалить командой `cargo clean`.

### 3. Настройка быстрого запуска (`ymtp`)

Чтобы запускать плеер из любого каталога терминала по короткой команде `ymtp`, создайте симлинк в `~/.local/bin`:

```bash
mkdir -p ~/.local/bin
ln -sf $(pwd)/target/release/yandex-music-tui ~/.local/bin/ymtp
```

*(Убедитесь, что `~/.local/bin` добавлен в переменную `$PATH` — в большинстве современных шеллов вроде Bash, Zsh и Fish это настроено по умолчанию)*.

## Запуск и флаги командной строки

```bash
# Обычный запуск плеера
ymtp

# Открыть страницу авторизации Яндекс OAuth в браузере
ymtp --login

# Авторизоваться по готовому токену или URL редиректа
ymtp --token "ВАШ_ТОКЕН"

# Сбросить сохранённый токен (выйти из аккаунта)
ymtp --logout

# Справка по флагам
ymtp --help
```

*(Если вы не создавали симлинк `ymtp`, запускайте бинарник напрямую: `./target/release/yandex-music-tui`)*.

При входе (`ymtp --login` или `l` в TUI) приложение регистрирует обработчик схемы `music-application://` в `~/.local/share/applications`. После авторизации в браузере нажмите кнопку **«Открыть приложение»** — токен автоматически вернётся в запущенный TUI. Если браузер не открывает кнопку, нажмите по ней правой кнопкой → «Копировать адрес ссылки» и вставьте ссылку в TUI (`t`) или в `ymtp --token "..."`.

Файл конфигурации сохраняется по стандарту XDG:  
`~/.config/yandex-music-tui/config.toml`
